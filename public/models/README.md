# Modelos 3D

Baixados automaticamente de repositórios públicos do GitHub (ver `scripts/download-assets.sh`).

| Arquivo | Origem | Licença |
| --- | --- | --- |
| `quaternius/Superhero_Male.gltf` (+ `.bin`, texturas) | Quaternius – *Universal Base Characters* | CC0 1.0 (domínio público) |
| `quaternius/Superhero_Female.gltf` (+ `.bin`, texturas) | Quaternius – *Universal Base Characters* | CC0 1.0 (domínio público) |

Orc e Lobisomem são gerados em tempo de execução a partir desses corpos (escala de ossos, cor e peças
procedurais: presas, focinho, orelhas, garras, cauda), e as animações Idle/Andar/Atacar/Defender são
geradas proceduralmente sobre o esqueleto (não vêm dos modelos).
